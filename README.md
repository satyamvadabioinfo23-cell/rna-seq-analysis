# RNA-seq Analysis

**Author:** Satyamvada Maurya  
**Field:** Bioinformatics and Computational Biology

## Overview

This repository contains scripts and documentation for
RNA-seq data analysis, gene expression profiling,
differential expression analysis and data visualization.

The goal is to provide reproducible workflows for
transcriptomic data analysis.

## Objectives

- Perform RNA-seq quality control and preprocessing.
- Analyze gene expression data.
- Identify differentially expressed genes.
- Visualize gene expression patterns.
- Interpret biological functions and pathways.

## Tools and Technologies

- R and Bioconductor
- Python
- FastQC
- MultiQC
- HISAT2 or STAR
- featureCounts
- DESeq2
- ggplot2
